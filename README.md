# 長ねぎ 生育トラッカー（デモ）

南相馬ねぎ出荷組合株式会社が、長ねぎ（春まき秋冬どり）の生産管理のために作っているツールのデモ版です。
相馬アメダスの気象データから **生育温度帯・生育ステージ・収穫開始日** を見える化し、**病害虫の予防防除のタイミング** を知らせます。

**デモページ：** https://taokayoshiyasu-stack.github.io/negi-tracker/

> 圃場・作付けグループ・農薬名はすべて架空のデータです。気象は気象庁 相馬アメダスの実測値（2026年3月1日〜9月15日）です。
> 画面で入力した内容は、見ている方のブラウザにだけ保存されます（「初期状態に戻す」で元に戻ります）。

## 普及指導員の方に見ていただきたい点

区切りの値は、一般的な資料と生産者の経験をもとに仮に決めたものです。**地域の実態に合っているか**をご意見いただけると助かります。
ご意見は [Issue（ご意見）](../../issues/new/choose) から書き込めます。メールでいただいた内容を、こちらで転記することもできます。

### 1. ネギの生育温度帯

| 区分 | 条件 |
|---|---|
| 適温 | 日平均気温 18〜23℃ |
| 低め | 日平均気温 18℃未満 |
| 高め | 日平均気温 23℃超 |
| 生育休止 | 最高気温 28℃以上 |

### 2. ネギハモグリバエ 7日防除サイクル

- 幼虫はふ化後およそ5〜7日で葉から出て蛹になるため、前回の防除から **7日** で次の防除を表示します（ひとまずの設定）。
- 参考表示：B系統の発育零点10.0℃・有効積算温度333.3日度から、1世代の目安日数を出しています。

### 3. 病害虫センサー（1マス＝1日、条件がそろった日数が伸びる）

| 病害虫 | 条件（注意日数／発生日数） |
|---|---|
| さび病 | 平均10〜22℃が連続（3／5）・雨1mm以上が連続（2／4） |
| べと病 | 平均10〜20℃が連続（3／5）・雨の日 直近7日中（3／5） |
| 黒斑病・葉枯病 | 平均20℃以上が連続（5／7）・雨1mm以上が連続（2／3） |
| 軟腐病 | 最高30℃以上 直近7日中（2／4）・雨20mm以上 直近7日中（1／2） |
| ネギアザミウマ | 平均23℃以上が連続（5／8）・雨なしが連続（3／6） |

すべての条件が「注意」を超えると注意、「発生」を超えると発生しやすい、と判定します。

### 4. 生育ステージの区切り（定植日からの積算平均気温）

| ステージ | 目安（定植後） |
|---|---|
| 定植・活着期 | 0〜250℃ |
| 初期生育期（中耕・追肥①） | 250〜700℃ |
| 土寄せ①・追肥② | 700〜1,100℃ |
| 梅雨期（土寄せ②） | 1,100〜1,500℃ |
| 高温期（夏越し・土寄せ③） | 1,500〜1,950℃ |
| 止め土寄せ・肥大期 | 1,950〜2,600℃ |
| 収穫開始期 | 2,600℃〜（止め土寄せ後650℃） |
| 収穫期（在圃・冬どり） | 12月〜翌2月 |

## 画面の構成

- **いま**：生育ステージ、収穫開始の予測、生育温度帯グラフ、ハモグリバエ7日サイクル、病害虫センサー
- **カレンダー**：日ごとの天気・気温・湿度・日照・降水、作業の予定と記録、病害虫リスクの印
- **栽培管理記録**：防除・追肥・土寄せ・収穫の記録を写真付きA4 PDFに（本番版はGmailで送信）
- **生育ステージ**／**気温データ**／**圃場**

## データ出典

- 気象庁「過去の気象データ」相馬アメダス（福島県 prec_no=36 / block_no=0285）
- 平年値：7〜12月は相馬の2016〜2025年の同月同日平均、1〜6月は気象庁の平年値（1991〜2020年）
- ネギハモグリバエ：京都府農林水産技術センター「ネギハモグリバエ防除マニュアル」（令和7年2月）

## 本番版との違い

本番版は claude.ai 上で動いており、毎朝アメダスの値を自動で取り込み、実際の圃場データ・記録を保存しています。
このデモは、その画面と計算をそのまま単体のHTMLファイル（`index.html`）にしたものです。
