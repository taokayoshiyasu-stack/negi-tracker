# 長ねぎ 生育トラッカー（デモ）

南相馬ねぎ出荷組合株式会社が、長ねぎ（春まき秋冬どり）の生産管理のために作っているツールのデモ版です。
相馬アメダスの気温から **生育ステージ・土寄せ時期・収穫開始日** を予測し、**病害虫の発生しやすい気象条件** を知らせます。

**デモページ：** https://taokayoshiyasu-stack.github.io/negi-tracker/

> 圃場・作付けグループ・農薬名はすべて架空のデータです。気温は気象庁 相馬アメダスの実測値（2026年3月1日〜9月15日）です。
> 画面で入力した内容は、見ている方のブラウザにだけ保存されます（「初期状態に戻す」で元に戻ります）。

## 普及指導員の方に見ていただきたい点

計算の区切りは、一般的な資料をもとに仮に決めた値です。**地域の実態に合っているか**をご意見いただけると助かります。
ご意見は [Issue（ご意見）](../../issues/new/choose) から、項目ごとのテンプレートで書き込めます。メールでいただいた内容を、こちらで転記することもできます。

### 1. 生育ステージの区切り（定植日からの積算平均気温）

積算気温は、基準温度を引かずに日平均気温を足し上げています。

| ステージ | 目安（定植後） | 主な作業 |
|---|---|---|
| 定植・活着期 | 0〜250℃ | かん水、土壌処理除草剤 |
| 初期生育期 | 250〜700℃ | 中耕、追肥① |
| 土寄せ①・追肥② | 700〜1,100℃ | 土寄せ①、梅雨前の排水対策 |
| 梅雨期 | 1,100〜1,500℃ | 土寄せ②、病害の予防散布 |
| 高温期（夏越し） | 1,500〜1,950℃ | 土寄せ③（控えめ） |
| 止め土寄せ・肥大期 | 1,950〜2,600℃ | 止め土寄せ |
| 収穫開始期 | 2,600℃〜 | 収穫開始 |
| 収穫期（在圃・冬どり） | 12月〜翌2月 | 順次収穫 |

- 収穫開始の予測：止め土寄せ日が入っていれば「止め土寄せ後 650℃」、なければ「定植後 2,600℃」
- 2,600℃・650℃は作付けグループごとに変更できます

### 2. 病害虫・気象リスクの判定条件（直近7日の気象）

| 項目 | 「高」の条件 | 「中」の条件 |
|---|---|---|
| さび病 | 平均気温10〜22℃ かつ 雨の日（1mm以上）3日以上 | 同気温で雨の日2日 |
| べと病 | 平均10〜20℃ かつ 雨の日3日以上 かつ 日照平均4時間未満 | 同気温で雨の日2日 または 日照3時間未満 |
| 黒斑病・葉枯病 | 平均20℃以上 かつ 雨の日3日以上 | 平均18℃以上 かつ 雨の日2日 |
| 軟腐病 | 最高30℃以上の日と20mm以上の雨の日が両方ある、または 平均25℃以上で7日雨量50mm以上 | 平均23℃以上 かつ 雨の日2日 |
| 白絹病 | 平均25℃以上 かつ 雨の日3日以上 | 平均24℃以上 かつ 雨の日2日 |
| ネギアザミウマ | 平均23℃以上 かつ 雨の日1日以下 | 平均18℃以上 かつ 雨の日2日以下 |
| ネギハモグリバエ | 平均25℃以上 | 平均18℃以上 |
| 湿害・根傷み | 直近3日の雨量50mm以上 | 3日30mm以上 または 7日80mm以上 |
| 高温障害 | 最高気温の7日平均32℃以上 | 30℃以上 |

### 3. 各ステージの「管理のポイント」の文章

「生育ステージ」タブで各ステージの文章を表示できます。表現や内容の修正もご意見ください。

## 画面の構成

- **いま**：現在のステージ、収穫開始の予測、次の作業、平年との差、病害虫リスク
- **レポート**：防除・追肥・土寄せ・収穫の記録をA4 PDFに（本番版はGmailで送信）
- **生育ステージ**：全ステージの到達日（実績・予測）と管理メモ
- **気温データ**：日別の気温グラフと表、積算気温カリキュレーター
- **圃場**：作付けグループ（定植日・止め土寄せ日・収穫開始日）と農地一覧

## データ出典

- 気象庁「過去の気象データ」相馬アメダス（福島県 prec_no=36 / block_no=0285）
- 平年値：7〜12月は相馬の2016〜2025年の同月同日平均、1〜6月は気象庁の平年値（1991〜2020年）

## 本番版との違い

本番版は claude.ai 上で動いており、毎朝アメダスの値を自動で取り込み、実際の圃場データ・送信履歴を保存しています。
このデモは、その画面と計算をそのまま単体のHTMLファイル（`index.html`）にしたものです。
